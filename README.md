## 🧭 Overview

**AI · ML · DL** is a structured, opinionated learning roadmap for mastering Artificial Intelligence, Machine Learning, and Deep Learning. Unlike scattered playlists or book lists, this roadmap follows a **linear, cumulative curriculum** — each phase unlocks the next.

| Metric | Count |
|--------|-------|
| **Phases** | 8 (0–7) |
| **Topics** | 30+ |
| **Curated Resources** | 100+ (courses, books, papers, repos, videos, websites) |
| **Duration** | 12–18 months |
| **Cost** | Free (all resources are free or have free tiers) |
| **Difficulty** | Beginner → Advanced |

The project includes two interfaces:
- **🏠 Home Page** — Roadmap overview, syllabus index, guidance system, and resource browser
- **📊 Interactive Dashboard** — Full phase-by-phase curriculum with modals for every resource

### Phase 0 — Python Foundation
Python is the universal language of ML. Master it before everything else.

**Topics:** Python Basics & OOP, NumPy, Pandas, Matplotlib

**Resources:**
- 🎓 CS50P (Harvard)
- 📚 Python Data Science Handbook (VanderPlas)
- ▶️ Corey Schafer OOP Series
- 🌐 Kaggle Pandas Course

---

### Phase 1 — Math for ML
ML is applied mathematics. Linear algebra, calculus, probability.

**Topics:** Linear Algebra, Multivariate Calculus, Probability & Statistics

**Resources:**
- ▶️ Essence of Linear Algebra (3Blue1Brown)
- 🎓 Imperial College Coursera
- 📄 Matrix Calculus for DL (Parr & Howard)
- 🌐 Seeing Theory (Brown University)

---

### Stages 1–2 — Classical ML
Bias-variance tradeoff, regularisation, cross-validation, feature engineering.

**Topics:** Supervised Learning, Unsupervised Learning, Ensembles & Boosting

**Resources:**
- 🎓 Andrew Ng ML Specialization
- 📚 ISLP (James, Witten, Hastie, Tibshirani)
- 📄 XGBoost Paper
- 📚 Hands-On ML (Géron)

---

### Stage 3 — Deep Learning
Neural networks, backpropagation, CNNs, RNNs, LSTMs.

**Topics:** Neural Networks, Regularization & Optimization, CNNs, Sequence Models

**Resources:**
- 🎓 Deep Learning Specialization (Ng)
- 📚 Neural Networks & DL (Nielsen)
- 📄 Dropout, Adam, ResNet Papers
- ▶️ Stanford CS224n

---

### Stage 4 — First Principles
Build every component of a neural network from scratch.

**Topics:** Autograd, Language Modeling, Transformer

**Resources:**
- ▶️ Neural Networks: Zero to Hero (Karpathy)
- 🐙 micrograd, makemore, Let's build GPT
- 📄 Attention Is All You Need
- 📚 The Annotated Transformer (Harvard)

## 🚀 Getting Started

### Prerequisites
- **Node.js** >= 22.12.0

### Setup

```bash
# Clone the repository
git clone https://github.com/AyushSahoo19/Everything-AI-ML-DL.git
cd Everything-AI-ML-DL

# Install dependencies
npm install

# Start the dev server
npm run dev
```

Open [http://localhost:4321](http://localhost:4321) in your browser.

### Commands

| Command | Action |
|---------|--------|
| `npm run dev` | Start local dev server at `localhost:4321` |
| `npm run build` | Build production site to `./dist/` |
| `npm run preview` | Preview build locally |

---

## 🌐 Deployment

The site is built with **Astro** and generates a static `dist/` folder that can be deployed to any static host:

- **[Vercel](https://vercel.com)** — Recommended (zero-config)
- **[Netlify](https://netlify.com)**
- **[GitHub Pages](https://pages.github.com)**
- Any static file server

Deploy with Vercel:

```bash
npm run build
npx vercel deploy --prod
```
